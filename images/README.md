# Images

Drop Ahaan's real assets here, then reference them from `index.html`.

Suggested files (swap the placeholder colored covers / sections for real images):

- `book-covers/` — favorite book covers
- `library.jpg` — a photo at the library
- `swing.jpg` — Ahaan on the swing
- `logos/` — any platform logos (e.g. a reading-log service)

Tip (same toolchain used for Vihaan's site): process phone photos with
`sips` (macOS) or Python PIL to crop/resize/compress before committing —
keeps the repo small and the page fast.
